Frequently asked questions

Is this real-money gambling?

No. SkyRocket is a demo built for entertainment. All balances are virtual coins with no monetary value. There are no deposits, withdrawals, cash prizes or real-money wagers.

Where is my balance stored?

In this browser's localStorage on your device. There is no server account, so clearing browser data or switching devices starts a fresh demo. Logging in only creates a local profile in the same browser.

How do I get more coins?

Open the bonuses page for free top-ups, or use the demo cashier. Cashier deposits are simulated and never contact a payment provider.

Can I withdraw coins or real money?

No. The cashier's withdrawal option only removes virtual coins to demonstrate the flow. Nothing is sent to a bank, UPI ID, card or crypto wallet.

How does the Aviator fairness check work?

The crash point is derived from HMAC-SHA256 using a server seed, client seed and nonce. The server seed hash is shown before the round and the full seed is revealed afterwards. Open Aviator and use the provably fair panel to recompute the last round.

Why did my demo progress disappear?

Progress is local to one browser and can be cleared by private browsing, storage cleanup or the reset button on your account page. It is not synced to a server.

Is this affiliated with Crorebet, Spribe or Aviator?

No. SkyRocket is an original demo interface and is not affiliated with any operator or game provider. Third-party names may appear for reference only.
