How to play

  1. Place a bet during the countdown. Your stake is taken from your demo balance.
  2. The rocket takes off and the multiplier climbs from 1.00x upward.
  3. Cash out any time to lock in stake × multiplier coins.
  4. If the rocket flies away before you cash out, the stake is lost.

Tip: set an auto cash out multiplier (e.g. 2.00) and the game will cash you out automatically. Use the ½ / 2× buttons for quick stake changes, and press Space to bet or cash out.

This is a demo with virtual coins. No money can be deposited or won.

Provably fair

Each round's crash point is derived from a server seed, your client seed and a round nonce using HMAC-SHA256. The hash of the server seed is published before the round; the seed itself is revealed after it ends, so you can verify the result.

Algorithm

hash  = HMAC_SHA256(serverSeed, clientSeed + ":" + nonce)
h     = int(hash[0..8], 16)          // first 4 bytes
e     = 2^32
crash = h % 33 == 0
      ? 1.00
      : floor((100·e − h) / (e − h)) / 100

The result is capped at 1000x. This demo runs fully in the browser, so the seeds are generated locally — it demonstrates the algorithm rather than enforcing it against a server.
